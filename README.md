# DocFlow

Учебный веб-сервис для локальной проверки документов. DocFlow определяет вид документа, подбирает план проверки и показывает найденные поля, цитаты и ошибки рядом с оригиналом. Поддерживаются PDF и изображения JPG, JPEG, PNG и WEBP.

Фото и сканы читает PaddleOCR. Qwen 3.5 4B в LM Studio извлекает поля. FastAPI формирует отчёт, а SQLite хранит историю.
