# DocFlow

**Статус:** первый спринт в работе. 

## Цель

Предполагаемый сценарий: получить документ, извлечь из него текст, найти нужные поля, проверить их по заданным правилам и показать человеку результат вместе с основаниями для проверки. Решение о пригодности документа остаётся за человеком до отдельного согласования критериев качества.

## Планируемый поток

1. Пользователь передаёт тестовый документ, разрешённый для использования в проекте.
2. OCR извлекает текст и, если возможно, координаты фрагментов.
3. Локальная LLM предлагает структурированные поля и объяснения со ссылками на фрагменты текста.
4. Детерминированные правила проверяют формат, обязательность и согласованность полей.
5. Человек просматривает исходный фрагмент, распознанный текст и результат проверок.

Это целевая схема, а не описание реализованного приложения.

## Первый спринт

В первом спринте формируется техническая основа DocFlow: уточняются сценарии обработки документов, состав извлекаемых полей и правила их проверки. Текущие задачи и ожидаемые результаты приведены в [дорожной карте](docs/roadmap.md), основные понятия - в [словаре](docs/glossary.md).

## Данные и безопасность

Для анализа распознанного текста будет использоваться локальная LLM, запущенная на компьютере или сервере проекта. Передавать документы и распознанный текст во внешние сервисы LLM не планируется. Конкретная модель и требования к оборудованию будут определены на этапе прототипа.
