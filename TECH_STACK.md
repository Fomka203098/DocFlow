# Технический стек

Для проекта выбраны Python 3.11, Flask и PostgreSQL. Библиотеки для OCR, конкретная локальная LLM и способ её запуска пока уточняются.

## Компоненты

- **Python 3.11** - язык разработки проекта.
- **Flask** - фреймворк для локального API и приёма документов.
- **PostgreSQL** - база данных проекта.
- **OCR** - извлечение текста и координат фрагментов. Конкретный движок будет выбран по результатам сравнения.
- **Локальная LLM** - извлечение полей в структурированном виде со ссылками на исходный текст. Модель будет запускаться на компьютере или сервере проекта без обращения к внешнему API LLM.
- **Правила в коде** - проверка обязательных полей, форматов и согласованности значений.
- **Локальное хранение** - тестовые файлы без реальных данных.
- **Синтетические примеры** - набор для повторяемой оценки OCR и извлечения полей.

## Критерии выбора

1. Качество на согласованных образцах документов, включая плохие сканы.
2. Возможность проследить вывод до фрагмента исходного документа.
3. Работа с русским текстом и нужными форматами файлов.
4. Ограничения по данным, стоимости, скорости и лицензиям.
5. Простота воспроизводимого запуска для двух участников команды.
