# Стартовый набор DocFlow

В `images/` лежат восемь синтетических заявлений о приёме на работу в трёх вариантах оформления. Все данные вымышлены. В `labels.jsonl` каждой картинке соответствует одна строка с эталонными полями и состоянием подписи. Пустые поля размечены как `null`. В образце `synthetic-05.png` специально указано `31.02.2026`. В отчёте ожидается ошибка календаря с сохранением исходной даты.

Загрузите PNG в DocFlow и сравните результат с `expected` в разметке. Сравнивайте смысл значений и соответствие цитат документу. Переносы строк, пробелы и окончания слов в ответе модели могут отличаться. Этот набор служит для быстрой проверки извлечения полей до дообучения.

Для следующей партии распечатайте новые вымышленные заявления и сфотографируйте их телефоном при обычном освещении, под небольшим углом и с тенью. Добавьте пустые и подписанные от руки бланки. Храните реальные фотографии отдельно от синтетики. Если используете набор для обучения, держите все снимки одного заявления в одной части набора и отложите часть заявлений только для итогового теста.
