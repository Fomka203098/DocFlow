История проверок

Здесь хранятся оригиналы и отчёты по загруженным документам.

Правила проверки

Qwen определяет вид документа по содержанию. От него зависит список полей в отчёте.

Планы по видам документов

Если вид не определён, применяется общий план.

Как читать отчёт

Найдено
Модель извлекла значение. Сверьте его с оригиналом.
Проверить
Поле отсутствует, не читается или требует проверки человеком.
Ошибка даты
Извлечённой даты нет в календаре.

Отчёт включает возможные противоречия внутри текста. Для планов с подписью Qwen ищет росчерк по изображению. Сверьте выводы с оригиналом.

О проекте DocFlow

DocFlow — учебный проект по проверке документов. Цель команды — извлекать нужные поля и показывать человеку результат проверки вместе с фрагментами исходного документа.
