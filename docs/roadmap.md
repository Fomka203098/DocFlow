# Дорожная карта

**Статус:** предварительный план.

## Спринт 1: уточнение задачи и технический опыт

| Задача | Проверяемый результат |
| --- | --- |
| Согласовать один минимальный сценарий и тип документа | Записаны входные форматы, поля и ожидаемые проверки |
| Определить требования к тестовым данным | Перечень разрешённых синтетических/обезличенных образцов и способ их подготовки |
| Сравнить OCR кандидатов | Таблица результатов по одинаковым образцам и выбор для прототипа |
| Описать формат результата | Пример структуры полей, ссылок на фрагменты и статусов проверок |
| Определить проверяемые правила | Список правил и примеры успешных/ошибочных случаев |
| Проверить извлечение полей локальной LLM на тестовом тексте | Протокол опыта с ошибками и случаями неопределённости; без заявления о готовом сервисе |

**Критерий завершения спринта:** команда может показать воспроизводимые результаты опытов на разрешённых данных и объяснить выбор следующего шага. Действующий продукт и автоматическое принятие юридически значимых решений не входят в этот критерий.

## Позже, после итогов спринта

Прототип сквозной обработки, интерфейс просмотра, тесты на расширенном наборе документов, политика обработки данных и развёртывание. Состав и порядок этих этапов будут пересмотрены после первого спринта.
