# Словарь

**Статус:** рабочие определения для обсуждения в первом спринте.

| Термин | Значение в проекте |
| --- | --- |
| Документ | Файл или изображение, поданное на обработку; допустимые форматы ещё не согласованы |
| OCR | Преобразование изображения текста в машинно читаемый текст |
| LLM | Языковая модель, которую планируется оценить для извлечения полей из текста |
| Поле | Значение, нужное для выбранного сценария проверки, например дата или номер; конкретный перечень предстоит определить |
| Фрагмент-основание | Часть распознанного текста и её положение в документе, на которые опирается предложенное значение |
| Правило проверки | Заранее записанное условие для поля или связи полей |
| Неопределённость | Случай, когда текста или надёжности недостаточно для уверенного значения |
| Эталон | Значение или текст, вручную проверенные для оценки результата опыта |
| Синтетический образец | Искусственно созданный документ без реальных персональных данных |
